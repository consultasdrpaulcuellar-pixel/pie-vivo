# Pie Vivo — prototipo

Prototipo navegable de la PWA Pie Vivo (control de pies entre consultas para personas con diabetes).

- `index.html`: App del paciente.
- `panel.html`: panel profesional y contenido clínico para revisión.
- `contenido.js`: todos los textos, preguntas y reglas de aviso. **Borrador sin validación clínica.**

Los controles se guardan en el dispositivo y se sincronizan con una base de prueba. Usar solo datos ficticios. No es un producto médico ni está autorizado para uso clínico.
